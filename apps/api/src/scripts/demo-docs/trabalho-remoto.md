# Trabalho Remoto na Acme Ltda. (exemplo fictício)

## Elegibilidade

O trabalho remoto é permitido até 3 vezes por semana, combinadas com o gestor direto. Durante o período de experiência, o trabalho é presencial.

## Equipamentos

A empresa fornece notebook, monitor e headset. O auxílio mensal para internet e energia é de R$ 150,00, pago junto com o salário.

## Acesso à rede

O acesso aos sistemas internos é feito somente pela VPN corporativa, com senha e um segundo fator gerado pelo aplicativo autenticador. A sessão da VPN expira após 8 horas.

## Horário e disponibilidade

O horário de disponibilidade é das 10h às 16h, para reuniões e atendimento. Fora desse intervalo, o colaborador organiza a própria jornada.
